The guide

How a session works

Four steps, no installs on the other end, done in under a minute.

1

Start a share

Click the Tab Controller icon on the tab you want someone else to help with, then choose "Share this tab." A one-time room code is generated.

2

Send the code

Send the code to the person helping you, however you'd normally reach them — chat, email, a call. They enter it in their own copy of the extension.

3

Approve the session

You'll see a clear on-screen prompt before anything happens. Approve it, and Chrome's debugging indicator confirms the session is active.

4

Hand over control — and take it back anytime

The other person sees a live mirror of your tab and can click, type, and scroll. End the session instantly from either side, at any time.
